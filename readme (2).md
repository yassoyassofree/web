# School Invincible

[![Netlify Status](https://api.netlify.com/api/v1/badges/4a852e63-e85f-4c92-bfb7-3af14edbf638/deploy-status)](https://app.netlify.com/projects/version133/deploys)

## Description
School Invincible is a Progressive Web App (PWA) designed for educational purposes. It features a login system and can be installed on your device for offline use.

## Features
- User authentication system
- PWA support with offline capabilities
- Modern UI design
- Secure login/register functionality

## Deployment
This project is deployed on Netlify. You can view the live version at: https://version133.netlify.app

## Development
The project is built using:
- HTML5
- CSS3
- JavaScript
- Service Workers for PWA functionality

## Installation
1. Clone the repository
2. Open `index.html` in your browser
3. Install the PWA using the install button
4. Use the app offline after installation
